🎵 Spotify Song Requests
Lets viewers request songs via !sr <song name> in your Twitch chat. Requires a free Spotify Developer account and a Spotify Premium subscription.
ℹ️ Twitch chat is read anonymously — no Twitch login or app setup needed. Only Spotify requires OAuth.
1

Create a Spotify Developer App

Go to the Spotify Developer Dashboard ↗, log in with your Spotify account, and click Create app. Any name works (e.g. "StreamKit"). Under APIs used, select Web API.

2

Add the Redirect URI

In your new app's Settings, find Redirect URIs and add the URL below exactly as shown — then click Save.

⚠️ This URL is tied to the port StreamKit is running on. If you change ports, update this URI in your Spotify app settings.

3

Copy your Client ID

Still in your app's Settings page, copy the Client ID — it's a 32-character hex string. You do not need the Client Secret (StreamKit uses PKCE, which is secret-free).

4

Connect in StreamKit

Open the Spotify tool from the sidebar, paste your Client ID, and click Connect to Spotify. You'll be redirected to Spotify to authorize, then brought back automatically.

5

Set your Twitch channel & go live

Back in the Spotify tool, enter your Twitch channel name and click Connect. Viewers can now type !sr song name or !sr artist - song. Toggle Auto-add to queue requests instantly, or leave it off to approve each one manually.

📺 Adding Overlays to OBS
StreamKit has four OBS-ready overlays with transparent backgrounds. Add each one as a Browser Source in OBS.
ℹ️ StreamKit must be running (serve.py) for OBS to load the overlays. They auto-refresh — no manual reload needed.
  1. In OBS, click + in the Sources panel and choose Browser.
  2. Give it a name, then paste the URL from below into the URL field.
  3. Set width and height as suggested, then click OK.
  4. Position and resize the source on your scene as needed.
🔊 Setting Up the Soundboard
The soundboard plays audio files from the assets/sounds/ folder. Drop your files in, then configure the buttons in the Soundboard tool.
1

Drop sound files into the sounds folder

Copy your audio files into:

Supported formats:

.mp3 .wav .ogg .flac .m4a
2

Configure a button

Open the Soundboard tool, hover over any button, and click the ✏️ icon. Set the label, choose an icon, and type the filename exactly as it appears in assets/sounds/ — for example: hype.mp3

3

Test it

Click the button — it should flash green while playing. Use the volume slider at the top to adjust. Keyboard shortcuts 1–9 trigger the first 9 buttons while the Soundboard is focused.

⚠️ Browsers block audio until the user interacts with the page. Click anything in StreamKit first, then sounds will play normally.
🟣 Connect Twitch
Linking Twitch unlocks live status in the sidebar, auto-fills your channel in the Spotify song request tool, and enables one-click clip creation from the Clip Notes tool.
ℹ️ Chat is read anonymously for !sr requests — no Twitch login needed for that. This setup is for the extra integrations above.
1

Create a Twitch Developer App

Go to the Twitch Dev Console ↗ and click Register Your Application. Any name works (e.g. "StreamKit"). Set Category to Website Integration.

2

Add the OAuth Redirect URL

Under OAuth Redirect URLs in your app, add the URL below, then click Create.

3

Connect from the StreamKit sidebar

Click Connect Twitch at the bottom of the left sidebar, paste your Client ID from the Twitch Dev Console, and click Connect. You'll be redirected to Twitch to authorize, then returned automatically.

4

You're live-aware

Once connected, the sidebar footer shows your profile picture and display name. While you're streaming, a pulsing ● LIVE badge appears at the top of the sidebar with your viewer count and current game.

✅
What unlocks after connecting:
· Live status + viewer count in sidebar
· Twitch channel auto-filled in Spotify & Raid Tracker tools
· "Create Clip" button in Clip Notes
· Stream Info manager (edit title, category, tags)
· Raid Tracker auto-connects to your channel
⚠️ Stream Info requires the channel:manage:broadcast scope. If you connected Twitch before v1.1, disconnect and reconnect to upgrade your token permissions.
