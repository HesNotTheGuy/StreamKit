Remote Control

Trigger StreamKit from a physical controller — a Stream Deck, Touch Portal, a Loupedeck, or a phone — by pointing a button at a local URL. No plugin to install in StreamKit; any controller that can send an HTTP request to your own machine works.

Your control URLs

Connect a Stream Deck

In the Stream Deck app, add a Website action to a button (or install the free "Web Requests" / "API Ninja" plugin for a silent request with no browser pop).
Paste one of the URLs above as the target, set the method to GET, and (for the Website action) enable "Access in background" so it doesn't open a tab.
Press the button — StreamKit reacts instantly. Repeat for each action you want on a key.

Other controllers

Touch Portal / Loupedeck: add a "send HTTP GET" / web-request action with the URL.
Phone or browser: bookmark the URL.
Open any tool: use the pattern /api/action/tool:<id>?token=… — e.g. tool:soundboard, tool:spotify, tool:alerts.
Security: the control server listens only on localhost (this machine), and every URL carries a private token so other apps can't trigger actions blindly. The token persists across restarts, so your saved buttons keep working. Keep these URLs to yourself — anyone you share them with could press your buttons if they're on your PC.
Remote control runs inside the installed StreamKit desktop app — it isn't available in browser-only dev mode (serve.py), because the control server is part of the desktop build. Launch the StreamKit app and reopen this page to see your controller URLs.
